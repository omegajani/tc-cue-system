Basisdaten

Name, Aufführungsdatum und Verhalten beim Ausfall der Timecode-Quelle.

Songs, Cues und Aufgabenlisten werden auf der Edit-Seite automatisch gespeichert. Dieser Button speichert nur die Basisdaten oben.

Sicherung und Austausch

Optional: Show als Datei sichern oder auf ein anderes TC-Cue-System übertragen.

Beim Import wird eine neue Show angelegt. Die aktuell geladene Show bleibt unverändert.
