Zugriff / Passwörter

Pro Gewerk zwei Passwörter: das Positions-Passwort schaltet die Positions-Auswahl frei (sieht nur die eigene Position), das Meister-Passwort meldet direkt als Meister an (sieht alle Cues des Gewerks). Das Admin-Passwort schaltet alles frei.

Leeres Admin-Passwort = kein Zugriffsschutz: jeder wählt Gewerk/Position frei und sieht alle Tabs. Passwörter werden mit „Speichern" in der Show abgelegt.
